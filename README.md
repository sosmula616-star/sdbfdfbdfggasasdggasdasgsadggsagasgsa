# Dialog Spy для личных чатов Telegram

Бот присылает в личку уведомления о правках и удалениях из выбранных чатов. При правке показывает автора и две цитаты с подписями Old и New. При удалении показывает автора и сохранённый текст в цитате. Фото приходит с ником автора над изображением. Вложения отправляются в исходном типе Telegram, например видео, голосовым или кружком.

Бот скачивает обычные фото, видео, голосовые и документы в зашифрованный локальный архив. После скачивания файл можно получить, даже если Telegram удалил его копию. Бот сохраняет файл в том виде, в каком Telegram его передал. Для фото выбирает наибольший доступный размер. Фотографии и видео, сжатые Telegram при отправке, сохраняются в доступном качестве. [Документация Bot API](https://core.telegram.org/bots/api#getfile)

Событие удаления содержит чат и ID сообщений. В уведомлении указаны автор оригинала и время получения события ботом, когда эти данные применимы. Если сообщение отсутствует в архиве, бот показывает только факт удаления. [События удаления](https://core.telegram.org/bots/api#businessmessagesdeleted)

## Первый запуск в Windows

1. Создайте отдельного бота командой `/newbot` в [@BotFather](https://t.me/BotFather). Откройте настройки бота и включите **Secretary Mode**. [Инструкция Telegram](https://core.telegram.org/bots/features#business-bots)
2. Откройте PowerShell в папке проекта. Для запуска нужен Python 3.11 или новее.

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   Copy-Item .env.example .env
   notepad .env
   ```

3. В `.env` вставьте токен из BotFather после `BOT_TOKEN=` и сохраните файл. Затем запустите бота.

   ```powershell
   .\.venv\Scripts\python.exe bot.py
   ```

4. Откройте ссылку, которую покажет консоль, в своём аккаунте Telegram и нажмите **Запустить**. Эта ссылка один раз привязывает аккаунт к архиву.
5. В Telegram откройте **Настройки → Автоматизация чатов** (**Chat Automation**), укажите имя своего бота и выберите личные чаты. Для уведомлений достаточно доступа к этим чатам. Права на отправку, удаление и отметку сообщений прочитанными боту не нужны. [Telegram FAQ](https://telegram.org/faq)
6. Попросите собеседника в одном из выбранных чатов отправить обычное текстовое сообщение, изменить его и удалить для обоих участников. В чате с ботом должны появиться уведомления о правке и удалении.

## Одноразовые медиа

В подключённом личном чате свайпните по «бомбочке» до открытия и отправьте любой ответ, например слово, эмодзи или стикер. Собеседник увидит этот ответ. Отдельная команда в исходном чате не нужна. Медиа придёт только в ваш личный чат с ботом. Команда `/media` работает в этом же чате.

Бот обрабатывает одноразовые фото, видео, голосовые и кружки, когда Telegram передаёт доступное вложение внутри ответа. Bot API пропускает отдельные обновления о самоуничтожающихся сообщениях. Команда в чате с ботом сама по себе не даёт доступа к исходному файлу. У вложений в ответах может отсутствовать признак таймера, поэтому ответ также может сохранить обычное вложение, которого ещё нет в архиве. [Поле reply_to_message](https://core.telegram.org/bots/api#message) · [Исходники Telegram Bot API](https://github.com/tdlib/telegram-bot-api/blob/master/telegram-bot-api/Client.cpp#L19635)

## Использование

- `/status` показывает состояние подключения.
- `/last` повторно показывает последнее сохранённое изменение или удаление.
- `/recent` показывает 10 последних правок, удалений и сохранений по ответу. Команда `/history 42` показывает все полученные версии сообщения с номером архива `42`. Номер есть в уведомлениях и списке `/recent`.
- `/media 42` присылает локальную копию вложения в исходном типе Telegram. Команда `/media 42 1` берёт вложение из первой версии сообщения.
- Бот обрабатывает события, которые Telegram передаёт после подключения. Для постоянной работы оставьте процесс запущенным. Telegram хранит необработанные события до 24 часов. [Получение обновлений](https://core.telegram.org/bots/api#getting-updates)
- Содержимое сообщений и очередь уведомлений зашифрованы в `data/<ID бота>.sqlite3`. Зашифрованные вложения находятся в `data/<ID бота>.media/`. При переносе архива положите исходный файл `<ID бота>.key` рядом с `bot.py` и обновлённым `archive.py`. Бот проверяет ключи в папке проекта и системной папке и выбирает подходящий к архиву. Для первого запуска ключ автоматически создаётся в `%LOCALAPPDATA%\Dialogspy\` на Windows или `~/.config/dialogspy/` на Linux. Сохраните этот ключ для переноса или восстановления архива.
- Команды и уведомления доступны только привязанному аккаунту. Для получения событий и отправки уведомлений бот обращается к Telegram Bot API.

## Новый архив с резервной копией

Остановите процесс бота. В папке проекта выполните один раз команду, которая перенесёт текущую базу и медиа в `data/backups/` и создаст пустой архив.

```bash
python3 bot.py --new-archive
```

Команда покажет папку резервной копии и завершится. Затем запустите бот обычной командой `python3 bot.py` и откройте новую ссылку привязки из консоли. Для чтения старого архива из резервной копии понадобится его исходный ключ.

## Команда .luv

Напишите `.luv` отдельным сообщением в подключённом личном чате. Бот удалит команду после появления первого кадра и будет редактировать одно текстовое сообщение: сердце из эмодзи увеличивается и пульсирует. В финале остаются большое сердце и «Я люблю тебя ❤️». Команда выполняется только от владельца привязанного аккаунта.

В настройках подключения бота включите права **Отвечать** и **Удалять все сообщения**. Telegram разрешает отправку от имени аккаунта в чатах с входящими сообщениями за последние 24 часа. Кадры обновляются с интервалом около 1–2 секунд, учитывая ответы Telegram. [Права бизнес-бота](https://core.telegram.org/bots/api#businessbotrights)

## Крупные вложения

Облачный Bot API скачивает файлы размером до 20 МБ. Для файлов большего размера можно запустить [официальный локальный сервер Bot API](https://github.com/tdlib/telegram-bot-api) с `--local` на той же машине, разместив его рабочий каталог на зашифрованном диске. При переносе уже подключённого бота сначала выполните [`logOut`](https://core.telegram.org/bots/api#logout) на облачном API, затем укажите `BOT_API_URL=http://127.0.0.1:8081` в `.env` и перезапустите бот. Локальный сервер скачивает файлы без ограничения облачного API и принимает загрузки до 2000 МБ. [Локальный Bot API](https://core.telegram.org/bots/api#using-a-local-bot-api-server)
